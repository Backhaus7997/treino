# Videos promocionales

Videos verticales (1080×1920) para redes, grabados en el emulador con datos de prueba. Cada uno viene en dos versiones,
`-con-musica` y `-sin-musica`.

Se guardan con **Git LFS** (`.gitattributes`). Para bajar los videos en un clon hace falta `git lfs install` y después
`git lfs pull`; sin LFS, cada `.mp4` es un puntero de texto.
